# Torpedo Box — темы оформления

Темы, которые клиент [Torpedo Box](https://github.com/digtaltech/torpedo_box) скачивает только при включении, чтобы не раздувать установщик.

| Папка | Тема |
|---|---|
| `apiary/` | «Арабская пасека» |

Каждая тема — `theme.css` (стили под классом `.theme-apiary` и т.п.) и картинки рядом с ним. Клиент берёт файлы по тегу через jsDelivr:
`https://cdn.jsdelivr.net/gh/digtaltech/torpedo-box-themes@<тег>/<тема>/theme.css`

Меняешь тему — ставь новый тег и обнови его в клиенте, старые версии клиента продолжат работать со своим тегом.
